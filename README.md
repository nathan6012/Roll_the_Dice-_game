# Roll the Dice – AI vs User
A simple **Python command-line 
dice game** where a **user plays 
against an AI opponent**. Both 
players roll a dice, and the game 
determines the winner based on the 
results. This project focuses on 
**game logic**, **randomization**, 
and **clean separation between 
game rules and user interaction**. 
---
## Features
- User vs AI gameplay - Random 
dice rolls (1–6) - Clear win / 
lose / draw logic - Command-line 
interface (CLI) - Clean, readable 
Python code - Easy to extend with 
new rules ---
